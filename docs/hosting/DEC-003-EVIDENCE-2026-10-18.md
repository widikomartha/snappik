## New bounded local spike: observed results

Hypotheses: (1) candidate scratch preflight can carry exact capped bytes over real sockets and cancel/clean up; (2) existing native decoder can resize a valid synthetic photo and reject an explicitly excessive pixel count. Setup: Windows x64, PowerShell 7.6.5, Node 24.18.0, npm 11.16.0; existing root lock/node_modules, sharp **0.35.5** / libvips **8.18.7**. No install or app build. Spike imports historical stageOriginal with synthetic policy and runs two dynamically allocated **loopback-only** HTTP servers. Decoder creates solid RGBA PNGs in its own temp folder and decodes each in a new child process. All own servers/fixtures cleaned up; no DB/provider URL consumed.

| Result | Exact command/action | Observed outcome |
|---|---|---|
| Failed — sandbox environment | `node --test spikes/dec003-hosting/transport.test.mjs` under default sandbox | 0/5, loopback `connect EACCES`; not a provider/product failure or passing cancellation check |
| Passed — permitted local loopback rerun | `node --test spikes/dec003-hosting/transport.test.mjs` | 5/5, exit 0, zero skipped. 50 MiB exact digest/length/private header; unknown-length overflow before success; stalled socket deadline; cancel before headers; cancel during delivery; empty scratch after each |
| Passed | `node spikes/dec003-hosting/decoder.mjs` | Two assertions/cases passed. 24 MP 6000x4000 valid PNG (474,766 compressed bytes) -> 640-wide JPEG; 48 MP 8000x6000 PNG (944,513 bytes) rejected at experimental 40 MP input bound |
| Passed — compatibility inspection | `node node_modules/next/dist/bin/next start --help`; inspect actual manifest/compiled files/SQL loader | CLI supports hostname/PORT, exit 0; current npm start overrides loopback. Compiled migrator exists; loader needs source SQL path. Not an executed provider release |
| Blocked — restore tooling | `Get-Command pg_dump,pg_restore -ErrorAction SilentlyContinue`; `Test-Path node_modules/@embedded-postgres/windows-x64/native/bin/pg_dump.exe` and corresponding pg_restore path | No tools found in PATH or bundled server package. No new client installation authorized/performed; no export/restore attempted. SQL copy/mock would not establish backup feasibility |

First successful HTTP rerun: case durations approximately 346/159/163/26/172 ms, total ~937 ms. First decoder child: 122 ms, process high-water RSS 103,336 KiB (~101 MiB); rejection child: 11 ms, 52,660 KiB. These are single local samples, not performance requirements. Child high-water includes Node/native loading, excludes fixture generation/parent and does not measure container/page-cache/scratch limits. A highly compressible solid PNG, concurrency one and tiny output cannot establish hostile-image bounds or recommend a 512 MB worker. Root native default concurrency observed 32 before spike override; job lane setting alone does not constrain it.

No decoder limit has been added to the product: **40 MP is an experiment**, not a new eligibility rule. The HTTP fixture is repeated signature bytes, not a valid photo; the separate PNG spike is valid. Synthetic no-op policy is not auth, stub upstream is not Drive, bare Node HTTP is not the Next media endpoint or Render edge. Missing: 50 MiB valid-format matrix, concurrent load/admission/slow client pacing, all supported decoders/EXIF/ICC/truncated/bomb cases, crash janitor/ACL/encryption, Linux/OOM/signal behavior and proxy timeouts. Existing PostgreSQL lease tests were not rerun because SQL/worker code is unchanged.
